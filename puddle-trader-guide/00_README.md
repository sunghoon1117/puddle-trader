2. `01_PROMPTS.md` 의 **0번 공통 규칙**을 Claude Code 첫 메시지로 입력
3. Phase 1 → 10 순서로 프롬프트를 하나씩 실행하고, 각 단계 **완료 기준**을 확인한 뒤 다음으로
